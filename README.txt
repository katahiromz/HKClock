# HK時計

## これは何？

時計というものは、不思議な道具だ。

数字だけを追うならスマートフォンの隅にあるデジタル表示で事足りる。それなのに私たちは、なぜかいまだに、針がくるくると回るアナログ時計に心を惹かれてしまう。理由はきっと単純で、針の動きには「時間が流れている」という実感が宿っているからだ。デジタル表示の「12:34」は瞬間の切り取りにすぎないが、アナログ時計の長針と短針は、いま現在も絶え間なく動き続けている。その健気な動きを眺めているだけで、なんだか心が落ち着く。

<img src="img/screenshot.png" />

「HK時計」は、そんなアナログ時計の魅力を、ブラウザやアプリの中にそのまま閉じ込めてしまおうという、ささやかな試みから生まれたシンプルなアナログ時計アプリだ。飾り気のない文字盤に、秒針・分針・時針が淡々と時を刻む。ただそれだけの、けれどそれだけで十分に美しいものを目指した。

※ HKは、博文片山の略です。実在の団体などとは関係ありません。

## こだわりのポイント

- **鑑賞に堪える見た目**：無骨になりがちなアプリの時計だが、光沢のある縁取りや影の効果にひと手間かけ、卓上に置かれた本物の置き時計のような質感を狙っている。
- **秒を刻む音**：右クリック（あるいは長押し）のメニューから「音声を再生する」をONにすると、コチコチという秒針の音を聞くことができる。無音の部屋にひとり佇むとき、この音がふと寂しさを紛らわせてくれることがある。もちろん、静けさを好む人のためにデフォルトはOFFにしてある。
- **軽い、それだけ**：特別なインストールも、面倒な設定も要らない。ブラウザさえあれば、いつでもどこでも同じ時計が現れる。
